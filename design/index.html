ExtendScript API — three representation concepts

All three are working prototypes driven by the real, complete object model extracted from temp/fixedDOM.xml. No frameworks, no CDN, no build step — plain HTML, CSS and vanilla JS, which is what the new XML→HTML transformation would emit.

Concept ACodex

The familiar Jongware model, done properly. One class at a time, dense tables, nothing new to learn. A veteran user is productive in the first second.

  • Filterable class rail, grouped A–Z
  • Sticky in-page member filter with live count
  • Copy .member to clipboard on hover
  • Type names link to their class or enum
  • Warm light theme + dark mode

Trade-off. Safest and fastest to build, but it does not solve “which class has geometricBounds?” — search stays scoped to one class.

Concept BConsole

Keyboard-first, three panes, dark by default. A command palette searches all 28,642 members at once — the answer to the question the current site cannot answer.

  • Ctrl/Cmd+K palette over every class, property, event and method
  • ExtendScript / UXP switch — UXP hides the 242 [] collection accessors plus $ and all 34 ScriptUI (…SUI) classes
  • Properties, events and methods each as their own table with own count
  • Clickable return types on every method
  • Enum values sit in the Type column, next to the type they belong to
  • Copy-to-clipboard on hover for every member
  • Object of and Return reverse lookups
  • Full inheritance chain (PageItem › SplineItem › Rectangle)
  • Runtime and theme survive a reload; the URL carries the mode (#Pages!uxp)

Trade-off. The most conventional “modern docs” answer, and the strongest everyday lookup. Slightly denser UI; the palette must be discoverable for non-keyboard users.

Open Concept B

Concept CAtlas

One search box drives everything, and you can pin two or three classes side by side. Members that exist in only one pane are flagged — the object model becomes explorable.

  • Single global input, scoped by chips (all / classes / props / methods)
  • Compare 2–3 classes; unique members marked in the margin
  • No page loads at all — every click is instant
  • Works offline as one folder, no server
  • Try Rectangle vs TextFrame: 19 / 36 unique members

Trade-off. The most useful for exploring and for questions like “what does Story have that Paragraph doesn’t”. But it is app-like: deep links and printing need extra work.
